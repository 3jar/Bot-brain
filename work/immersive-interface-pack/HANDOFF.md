# immersive-interface-pack — HANDOFF (2026-11-08)

Profile: ModrinthApp/profiles/Fabulously Optimized (2), MC 26.3 (resource format 97.1), guiScale 3, lang en_us.
Pack: resourcepacks/Immersive-Interfaces-main (Shrimpsnail's Immersive Interfaces, GitHub dev branch; the last official Modrinth release, 0.8.2, only goes up to 26.1.2).

## Symptoms (owner)
Hotbar/HUD restyle shows, but container backgrounds are missing; chest/inventory GUIs look garbled ("old pack on a newer version").

## Root causes found
1. The GitHub repo ships no generated lang files (pack.mcmeta references a `_1.21_lang` overlay that does not exist). Container backgrounds are font glyphs appended to titles via lang (e.g. container.chest = "Chest"), so without lang no background is drawn. The official release has assets/minecraft/lang/*.json (62 keys, generated by assets/minecraft/lang_creator.py).
2. Redstone Tweaks 2.5.6 (priority above II) overrides container.chest/chestDouble/barrel/dispenser/dropper/hopper/furnace/smoker/blast_furnace/brewing/shulkerBox with its own signal-strength guide glyphs (respackopts tooltips.ss_override=select, all ss_* true). This blocks II's titles and draws RT guides at vanilla positions.
3. The local copy was the 2026-10-01 snapshot. Upstream fixed chest row detection on odd GUI sizes (PR #109, 2026-11-07), and the "pc change" commit reworked the HUD textures.
